# Workflow: Research Brief Report

**When to use this:** Maddie asks for a write-up on a trend, tool, or topic
for an executive audience — e.g. "what's the latest on remote work trends" or
"summarize how Copilot/Forms/Flow can automate approvals." This is the recipe
already used for output/Remote_Work_Trends and
output/Copilot_Forms_Flow_Approvals.

## Inputs needed from Maddie

- The topic, and how current the data needs to be (last quarter, last year).
- Any specific angle she wants covered (e.g. a specific tool stack, a specific
  industry) versus a general overview.
- Whether this is a one-off or something she'll want refreshed later — if
  it's recurring, note that so it can be flagged as a candidate for a
  scheduled task.

## Steps

1. Confirm scope with a clarifying question if the topic is broad.
2. Research using current web sources — do not rely on memorized figures for
   anything that changes over time (statistics, pricing, org policies).
3. Draft the report as prose organized under a small number of clear section
   headers (Current Landscape, Key Findings, Sentiment/Impact, Sources — adapt
   labels to the topic). No bullet-heavy formatting inside sections; write in
   paragraphs the way the existing two reports do.
4. Include a Sources section at the end listing every source with its title
   and URL — never state a statistic without one.
5. Export as a Word document (.docx), concise and straight to the point, no
   raw data tables or embedded report data inside it.
6. Save to output/<Topic_Name>/ alongside any diagrams or supporting scripts,
   following the existing naming pattern (Topic_MonthYear.docx).
7. Tell Maddie the folder was created/used before finishing.
